# Nexus: Eternal War · Descargas

Action-RPG de agentes para Android. **Gratis, sin compras y sin pay-to-win.**

## Instalar
1. Abre la [última versión](https://github.com/JacobGT/Nexus-Eternal-War-Builds/releases/latest) desde el móvil.
2. Descarga el archivo `NexusEternalWar-x.y.z.apk`.
3. Ábrelo y permite *instalar apps de origen desconocido*.

Las actualizaciones pequeñas se descargan **dentro del juego**. Si una versión necesita un APK nuevo,
el juego te avisa y te trae aquí.

# Nexus: Eternal War · Downloads

Agent action RPG for Android. **Free, no purchases, no pay-to-win.**

1. Open the [latest release](https://github.com/JacobGT/Nexus-Eternal-War-Builds/releases/latest) on your phone.
2. Download `NexusEternalWar-x.y.z.apk` and open it (allow installing from unknown sources).

Small updates download **inside the game**. When a new APK is required, the game tells you and brings you here.
